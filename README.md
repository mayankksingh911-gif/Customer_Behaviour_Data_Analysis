Project Overview

This project analyzes customer shopping behavior using Python (Pandas) and SQL to uncover patterns in customer spending, product preferences, discount usage, subscription behavior, and customer loyalty.

The objective is to transform raw transactional data into actionable business insights by combining data cleaning, feature engineering, and analytical SQL queries. The project focuses on answering real-world business questions such as:

Which customer segments generate the highest revenue?
Do subscribed customers spend more than non-subscribed customers?
Which products receive the highest customer ratings?
How effective are discounts in influencing purchases?
What products are most popular within each category?
How does customer loyalty impact subscription behavior?

The workflow includes:

Data cleaning and preprocessing using Pandas
Handling missing values
Creating customer age segments
Transforming purchase frequency data into numerical metrics
Writing SQL queries to perform customer and product analysis
Generating business insights from customer purchasing patterns

This project demonstrates practical skills in Data Cleaning, Feature Engineering, SQL Analytics, Exploratory Data Analysis (EDA), Customer Segmentation, and Business Intelligence.
